Trust boundaries

The hard parts are explicit.

When is an answer actually reused?

Only when the relevant question, corpus, source revisions, settings, policy and model path still match. A cached answer can be fast but stale; quality tests deliberately bypass the cache. Source identity and model context are different types of state.

Does the graph make the answer smarter?

Not established. The current visible graph links documents, headings, shared terms and feedback. It is a diagnostic, not proof of semantic relationships or better retrieval. An independent benchmark must justify graph-based execution.

Can visitors upload private documents to this public demo?

No. The host is explicitly in an ephemeral, read-only demo posture. Custom uploads, visitor model keys and destructive mutation paths are refused server-side. Private workspaces and durable storage require separate authenticated infrastructure.

Why are extracts shown instead of a fluent answer?

The public host has no configured server generation key. Its extractive response quotes source material; it does not pretend a model synthesized the conclusion. This makes the lack of model availability visible rather than hiding it behind sample prose.
